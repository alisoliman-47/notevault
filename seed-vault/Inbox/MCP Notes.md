# MCP Notes

Start from [[Start Here]] if you are new. After reading through the vault, the most interesting piece so far is [[Concepts/MCP]]. The Model Context Protocol is what lets an AI agent interact with the vault through the same structured API that the human UI uses — meaning reads, writes, and searches all go through one consistent interface.
